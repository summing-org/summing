# 2026-08-18

## Admin Mini App отвязывает Project от отдельного Telegram-топика

- В каждой существующей topic binding появилась кнопка **«Отвязать»** с явным
  подтверждением удаления локального Codex-контекста и истории запусков.
- Новый идемпотентный administrator-only `DELETE /api/viewer/admin/bindings`
  валидирует `chat_id + topic_id` и атомарно удаляет Conversation. Запрос
  отклоняется при активном turn, runtime processor или ожидающем input, поэтому
  выполняющаяся работа не может потерять маршрут во время run.
- Удаление каскадно очищает Codex threads, runs и consumed inputs привязки, но
  сохраняет обнаруженные Telegram chat/topic, наблюдаемых пользователей и Team
  Space evidence. Повторная привязка того же топика начинает чистую Conversation
  с прежним детерминированным ID; физический Git worktree автоматически не
  удаляется.
- Добавлены регрессии StateStore, API и Mini App; версия SUMMING повышена до
  9.13.0.

## Node recovery для полного rebuild VPS

- Добавлен отдельный формат `summing-node-recovery` v1, не смешанный с переносимым Team Space: основной SQLite снимается через online backup и очищается от `team_*`, а успешные Team Space export перечисляются в manifest только по object key.
- Recovery разбит на независимо зашифрованные AES-256-GCM/gzip компоненты с SHA-256 каждого файла, HMAC manifest, безопасными archive paths/symlinks и публикацией `manifest.json` последним как commit marker.
- В node bundle входят conversations/runs, runner-control, стабильный node ID, identity/project memory, Codex session JSONL, artifacts, attachments и Git workspaces как repository bundle + staged/working binary patches + untracked. Помимо каталогизированных workspace автоматически обнаруживаются осиротевшие Git repositories/worktrees в managed roots. Generated dependencies/caches и Codex/OAuth auth state исключены; export блокируется, если хотя бы одна текущая Team Space не имеет свежего успешного bundle.
- Опциональный secrets-компонент требует точного `INCLUDE SECRETS`: сохраняет SUMMING config/env/keys, connector-only `core.sqlite`, TDLib session, repository credentials и project environments, полученные через runner. Recovery key показывается один раз, а durable job хранит только envelope под локальным transfer key.
- Добавлены отдельная durable SQLite queue, owner-only Admin API и экран **Система → Node recovery** с export, dry-run, классификацией sessions (`resumable`, `archive_only`, `broken_dependency`), явным подтверждением staging и bounded ошибками.
- Fresh install устанавливает root-команду `restore-node-recovery`: ключ читается скрыто через `/dev/tty`, bundle повторно скачивается и проверяется независимо от app staging, services останавливаются, разрешённые пути восстанавливаются с root-only rollback, а при ошибке выполняется обратное копирование и services остаются остановленными.
- Документирован порядок rebuild: старый VPS нельзя удалять до `succeeded`, сохранения bundle/recovery keys и успешного dry-run. Версия SUMMING повышена до 9.12.0.

## Полная переносимость Team Space

- Заменён source-scoped knowledge bundle на `summing-team-space-transfer` v2: export теперь выбирается по `spaceId` и атомарно снимает SQLite snapshots `state/core` для всех источников пространства.
- В bundle входят Team Space, sources, people/identities, events и revisions, knowledge/evidence/supersessions, consent и unknown-author state, synthesis audit, interventions, project links, checkpoints, content-addressed originals, canonical blocks, chunks и совместимые embeddings.
- Исправлен дефект v1, при котором state-таблицы экспортировались по всему пространству, а core-таблицы — только по одному `source_id`; multi-source round-trip и идемпотентный reimport покрыты тестом.
- Portable bundle получил отдельный случайный recovery key. Durable job хранит только AES-256-GCM envelope под локальным `kb-transfer.key`; raw key показывается администратору один раз и переносится на другую VPS без копирования серверного master key.
- Import проверяет HMAC, AES-GCM, checksums, catalog metadata и полный source manifest, выполняет dry-run конфликтов, сохраняет локальные consent revokes и пересобирает производный search index.
- Admin Mini App теперь выбирает Team Space, показывает число sources/project dependencies, принимает recovery key для import и выводит импортированные источники, которым требуется локальный MTProto connector и идемпотентный reconciliation backfill.
- Связанные project IDs переносятся как явные зависимости. Репозитории, worktree, Codex authorization, Bot API/MTProto credentials, operational queues и node configuration остаются ресурсами ноды и не копируются в Team Space bundle.
- Версия SUMMING повышена до 9.11.0.
