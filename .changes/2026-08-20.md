# 2026-08-20

## Artifact download token имеет единственное каноническое представление

- Viewer отклоняет неканонические Base64URL-сегменты до AES-GCM-дешифрования.
  Изменённая строка download token больше не принимается даже тогда, когда
  permissive decoder преобразует её в те же байты из-за незначащих padding bits.
- Регрессия отдельно проверяет криптографически изменённый token и его
  byte-equivalent неканонический alias, устраняя случайное падение deployment
  test на ответе `200` вместо `401`.
