# 2026-08-25

## Mini App: проекты и привязки топиков разделены

- Общий раздел «Управление» заменён двумя самостоятельными вкладками: «Проекты» и «Привязки топиков».
- У каждой вкладки теперь собственная панель, вводный блок и релевантные счётчики; каталог и создание проектов больше не смешаны со списком Telegram-топиков.
- Очередь «Доставка заказчику» размещена вместе с привязками внешних топиков и загружается/обновляется только в этом разделе; при уходе со вкладки её polling останавливается.

## Release 9.20.2

- Bumped SUMMING from `9.20.1` to `9.20.2` for default-branch-aware scheduled runner jobs.

## Resolve scheduled runs from the published default branch

- Stopped passing the legacy hard-coded `master` schedule marker directly to `git rev-parse`.
  Scheduled jobs now reuse SUMMING's existing default-branch detection and pin the exact commit
  from `origin/<default>` when it is published, with a local default-branch fallback for repositories
  that have not been published yet.
- Added a regression for the production failure mode where the workspace has an old local `main`,
  no local `master`, and the current runnable commit is available only as `origin/master`.
