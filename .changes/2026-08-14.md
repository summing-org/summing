# 2026-08-14

## Bare bot mentions stay local

- A message containing only the bot's `@mention` in an unbound Telegram topic now
  receives a concise prompt to include a question instead of starting a projectless
  Codex thread and exposing a low-level App Server error.
- The ping is handled before participant quota, volatile context, and the projectless
  worker queue, while substantive mentions and replies keep their existing isolated
  Q&A behavior. Low-level projectless startup/runtime failures remain in server logs and
  are replaced by a concise retry message in Telegram. Added routing and error-boundary
  regressions and advanced SUMMING to 9.2.3.

## Linked-worktree Git metadata remains writable for Project owners

- Owner/editor runs now carry the project-scoped common Git directory alongside the
  conversation worktree in `runtimeWorkspaceRoots` for `thread/start`, `thread/resume`,
  and `turn/start`. This prevents a turn override from silently dropping the linked
  worktree metadata root and blocking `fetch`, commit, or rebase.
- Read-only participant and projectless turns still exclude every Git metadata root.
  Added App Server contract regressions for write/read-only start, resume, and turn
  boundaries, documented the invariant, and advanced SUMMING to 9.2.2.
